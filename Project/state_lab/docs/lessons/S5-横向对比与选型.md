## 一、怎么读 s5

1. **先看 §0 总表**：五方案十个维度一屏扫完，建立坐标系。
2. **再读 §1 代码并排**：同一个"加购"动作五种写法、同一个角标五种订阅、同一个防抖两种世界——建议开着 `lib/versions/` 边读边对照真代码。
3. **§2 重建范围**：机制光谱（手工点名 → 自动判等）+ S2 实测数据回收。
4. **§4 决策树**：背下来的不是结论，是**每个分叉的判断条件**。
5. **§6 面试题 20 道**：前 5 道跨方案原理题是含金量最高的——答得出它们，说明五个方案在你脑子里是一张图，不是五份文档。

## 二、动手清单（比读更重要）

1. **五版并排 diff**：
   ```bash
   # 任何两版的 diff = 纯状态管理差异（shared 层保证）
   diff -r lib/versions/v1_provider/pages lib/versions/v2_bloc/pages
   diff -r lib/versions/v2_bloc/pages lib/versions/v3_getx/pages
   ```
   重点看每版 `_openCart`（re-provide 的有无）和购物车状态层（可变/不可变/Rx 三种世界）。
2. **RebuildBadge 横评**：依次进 v1/v2/v3，列表页连续加购 5 件，记录"列表角标"badge 计数与商品卡是否陪跑；进各版购物车增减数量，记录"合计栏"计数。把三组数字填进自己的笔记——这是 §2 结论的亲手复核。
3. **给自己出题**：用 §4 决策树给你手头/经历过的真实项目做一次选型推演，写下"选什么、代价是什么、怎么兜底"三句话（面试题 20 的标准答法练习）。
