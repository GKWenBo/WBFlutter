# Flutter 常用动画速查（iOS 开发者视角）

> 配套工程：`Project/animation_example`。打开 App → 首页按「隐式 → 显式 → 转场 → 列表 → 手势物理 → 自绘」分组，每个 Demo 页顶部有 iOS 类比 + 要点卡。

---

## 1. 先选型：我该用哪种动画？

```
需要动画？
├─ 只是属性 A → B 的一次性过渡？
│   ├─ 有现成 AnimatedXxx（Container/Opacity/Align/Padding/Positioned…）→ 用它 ✅ 最常用
│   ├─ 换一个子组件（文字/图标/整块内容）→ AnimatedSwitcher（记得给 key）
│   ├─ 展开收起 → AnimatedSize / AnimatedCrossFade
│   └─ 没有现成组件（进度、数字、颜色）→ TweenAnimationBuilder
├─ 要循环 / 暂停 / 反向 / 拖进度 / 多段编排？→ 显式动画 AnimationController
│   ├─ 有现成 XxxTransition（Fade/Scale/Rotation/Slide/Size）→ 用它
│   ├─ 自己组合属性 → AnimatedBuilder
│   └─ 多个元素依次入场 → Interval 交错动画
├─ 页面之间？
│   ├─ 共享元素飞过去 → Hero
│   └─ 自定义进出场 → PageRouteBuilder（要侧滑返回就用 CupertinoPageRoute）
├─ 列表增删 → AnimatedList
├─ 跟手 + 松手回弹 → GestureDetector + SpringSimulation + animateWith
└─ 图形本身在动（进度环、波浪、图表）→ CustomPainter(repaint: animation)
```

**一句话心智**：隐式 = 「告诉我终点，过程我包了」；显式 = 「给你一个时间轴，你自己用」。

## 2. 核心概念对照

| Flutter | iOS 对应 | 差异 / 说明 |
|---|---|---|
| 隐式动画 `AnimatedXxx` | `UIView.animate { 改属性 }` / SwiftUI `.animation(value:)` | Flutter 是 setState 改状态 → 重建，组件发现新旧值不同自己补间 |
| `AnimationController` | `UIViewPropertyAnimator` / `CADisplayLink` | 时间驱动器，value 0→1；可 forward/reverse/repeat/stop/animateTo，可直接赋 value |
| `vsync` / `TickerProvider` | `CADisplayLink` 绑屏幕刷新 | 页面不可见时自动暂停；`SingleTickerProviderStateMixin`（1 个）/ `TickerProviderStateMixin`（多个） |
| `Tween` | `CABasicAnimation.fromValue/toValue` | 把 0→1 映射到目标值域：`Tween<double>` / `ColorTween` / `IntTween` / `Tween<Offset>` |
| `Curve` / `CurvedAnimation` | `CAMediaTimingFunction` / `.curveEaseInOut` | `Cubic(x1,y1,x2,y2)` ≈ `controlPoints:` |
| `Interval` | `CAAnimationGroup` + `beginTime` | 把总时长切成区间，做交错 |
| `Hero` | SwiftUI `matchedGeometryEffect` | UIKit 需要自定义转场，Flutter 两行搞定 |
| `PageRouteBuilder` | `UIViewControllerAnimatedTransitioning` | `animation` 管我进来，`secondaryAnimation` 管我被盖住 |
| `AnimatedList` | `insertRows/deleteRows(with:)` | 同样必须"先改数据源再通知 UI" |
| `SpringSimulation` | `usingSpringWithDamping` / `UISpringTimingParameters` | 用 `stiffness/damping/mass` 描述，可带初速度 |
| `CustomPainter` | `CAShapeLayer` / `CGContext` | `repaint: animation` 每帧只重绘不重建 |
| `Matrix4..setEntry(3,2,0.001)` | `transform.m34 = -1/500` | 3D 透视 |

## 3. 控件速查表

### 3.1 隐式动画

| 控件 | 怎么用（关键参数） | 坑 |
|---|---|---|
| `AnimatedContainer` | 原 Container 参数 + `duration` (+ `curve`, `onEnd`) | 弹性曲线会冲过头，某些属性（如负尺寸）会报错 |
| `AnimatedOpacity` | `opacity` + `duration` | 透明度 0 仍占位、仍可点击 → 配合 `IgnorePointer` / `Visibility` |
| `AnimatedAlign` / `AnimatedPadding` | `alignment` / `padding` + `duration` | — |
| `AnimatedPositioned` | `left/top/right/bottom` + `duration` | 必须是 `Stack` 的直接子组件 |
| `AnimatedRotation` / `AnimatedScale` / `AnimatedSlide` | `turns`(圈) / `scale` / `offset`(自身尺寸倍数) | 单位不是角度和像素 |
| `AnimatedDefaultTextStyle` | `style` + `duration` | — |
| `AnimatedSwitcher` | `child` + `duration` + `transitionBuilder` | ⭐ child 必须带随内容变化的 `ValueKey`，否则不播 |
| `AnimatedCrossFade` | `firstChild` / `secondChild` / `crossFadeState` | 两个 child 都会被构建 |
| `AnimatedSize` | 包住会变尺寸的内容 + `duration` + `alignment` | 控制从哪边展开用 `alignment` |
| `TweenAnimationBuilder<T>` | `tween: Tween(end: x)` + `builder(ctx, value, child)` | `begin` 只首次生效；静态子树放 `child` |

### 3.2 显式动画

| 控件 / API | 怎么用 | 坑 |
|---|---|---|
| `AnimationController` | `AnimationController(vsync: this, duration: ...)`；`forward/reverse/repeat(reverse:)/stop/reset/animateTo` | ⭐ `dispose()` 里必须释放；**在 initState 创建**，别依赖 `late final` 懒加载（首次访问若在 dispose 里会崩，见拖拽 Demo） |
| `CurvedAnimation` | `CurvedAnimation(parent: c, curve: ..., reverseCurve: ...)` | 它会监听 parent，作为字段创建一次，别在 build 里反复 new |
| `XxxTransition` | `FadeTransition(opacity: anim)`、`ScaleTransition(scale:)`、`RotationTransition(turns:)`、`SlideTransition(position:)`、`SizeTransition(sizeFactor:)` | 传 `Animation` 对象而不是值；`SizeTransition` 的 `axisAlignment` 3.41 起废弃，改用 `alignment` |
| `AnimatedBuilder` | `animation` + `builder(ctx, child)` + `child` | ⭐ 不变的子树放 `child` 复用 |
| `Interval` | `CurvedAnimation(parent: c, curve: Interval(0.2, 0.6, curve: ...))` | 参数是比例 0~1 |
| `Curves.*` / `Cubic` | `Curves.easeInOut`、`fastOutSlowIn`、`easeOutBack`、`elasticOut` | `easeOutBack/elasticOut` 输出 >1，给 Opacity 用会断言失败 |

### 3.3 转场 / 列表 / 手势 / 自绘

| 控件 / API | 怎么用 | 坑 |
|---|---|---|
| `Hero` | 两页面同 `tag` 包住对应元素，正常 push/pop | 同页 tag 必须唯一；飞行中 Text 可能有黄下划线 → 包 `Material(type: transparency)` |
| `PageRouteBuilder` | `pageBuilder` + `transitionsBuilder` + `transitionDuration` | 默认无侧滑返回 |
| `CupertinoPageRoute` | iOS 原生风格 push，带侧滑返回 | — |
| `AnimatedList` | `GlobalKey<AnimatedListState>`；`insertItem(i)` / `removeItem(i, builder)` | 数据源与调用不同步 → 越界崩溃 |
| `Dismissible` | `key` + `background/secondaryBackground` + `confirmDismiss` + `onDismissed` | key 唯一稳定；`onDismissed` 必须同步删数据 |
| `SpringSimulation` | `SpringSimulation(SpringDescription(mass, stiffness, damping), start, end, velocity)` + `controller.animateWith(sim)` | 用 `AnimationController.unbounded`；记得传松手速度 |
| `CustomPainter` | `super(repaint: animation)`，`paint()` 里读 `animation.value` | `shouldRepaint` 只比较配置；动画交给 `repaint` |

## 5. 性能要点

1. **能隐式就隐式**，代码少、不用管生命周期。
2. 显式动画别用 `addListener + setState` 重建整页；用 `XxxTransition` / `AnimatedBuilder` 局部刷新。
3. `AnimatedBuilder` / `TweenAnimationBuilder` 的 `child` 参数用起来。
4. `CustomPainter` 用 `repaint:` 驱动；复杂静态部分用 `RepaintBoundary` 隔离。
5. 无限循环的动画（`repeat()`）在页面销毁时一定要 `dispose()`。
6. 测试里遇到 `repeat()` 不能用 `pumpAndSettle`（永远不 settle），改为 `pump(duration)` 若干次。

## 7. 课后练习

1. **点赞动画**：点击心形 → 放大到 1.3 再弹回 1.0，同时颜色从灰变红（提示：`TweenSequence` 或 `AnimatedScale` + `easeOutBack`）。
2. **骨架屏 Shimmer**：用 `AnimationController.repeat()` + `LinearGradient` 的 `transform: GradientRotation / 平移` 做一个闪光加载占位。
3. **购物车抛物线**：点击商品图片，一个小球沿贝塞尔曲线飞到右上角购物车图标（提示：`Overlay` + `AnimatedBuilder` + 二次贝塞尔插值）。
4. **底部弹窗跟手**：自己实现一个可拖拽的底部面板，松手根据速度决定展开/收起（提示：拖拽 Demo 的 `animateWith` + `DraggableScrollableSheet` 对比）。
5. **给 AnimatedList 加"撤销删除"**：SnackBar 点撤销后把数据插回原位置并播放插入动画。
